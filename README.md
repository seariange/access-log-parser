# Парсер серверных access-логов

Парсер лог-файлов веб-сервера на Java с расширенной статистикой.

# Описание
Проект предназначен для анализа логов веб-сервера и получения статистики:
- Доля запросов от поисковых ботов (Googlebot, YandexBot)
- Распределение по типам операционных систем и браузерам
- Средний трафик сайта за час
- Подсчёт количества HTTP-методов (GET, POST и др.)

Лог-файл должен быть в формате Apache/Nginx, например:
10.142.178.73 - - [25/Sep/2022:06:25:04 +0300] "GET /data.php?rss=1&json=1&lg=1 HTTP/1.0" 200 49161 "-" "-" 
72.118.143.231 - - [25/Sep/2022:06:25:06 +0300] "GET /parliament/november-reports/content/6377/58/?n=13 HTTP/1.0" 200 8983 "-" "Mozilla/5.0 (Linux; Android 6.0.1; Nexus 5X Build/MMB29P) Chrome/105.0.5195.125 Mobile Safari/537.36"
